# Documentation

Canvas is a publishing package for Laravel. Authors write in the admin at `/canvas`; your application owns authentication and the public site.

| Page                                | Description                            |
| ----------------------------------- | -------------------------------------- |
| [Installation](./installation.md)   | Require the package and open the admin |
| [Configuration](./configuration.md) | Options in `config/canvas.php`         |
| [Authorization](./authorization.md) | Roles, access, and the host user model |
| [Canvas UI](./canvas-ui.md)         | Optional public reader at `/canvas-ui` |
| [Content](./content.md)             | Querying posts and rendering bodies    |
| [Webhooks](./webhooks.md)           | Lifecycle events and outbound HTTP     |

Major upgrades are documented in [UPGRADE.md](../.github/UPGRADE.md).
